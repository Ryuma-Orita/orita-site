A little care went into the look of this site. Most of it is easy to miss,
so here is a note about it.

### Colours

The palette changes each time you arrive. Seven of them — red, orange,
yellow, green, blue, indigo, violet — have a pattern drifting slowly across
the background. The eighth stands still.

That eighth one borrows the colours of Dick Bruna's picture books: a few
primaries and a black outline, and nothing else. The favicon and the image
that appears when the address is shared use the same palette.

The palette stays put while you move around the site. It is chosen again
once you have been somewhere else and come back.

### The drifting pattern

The pattern is two layers. The far one has smaller, thinner, fainter shapes
and moves slowly. The near one has larger, bolder, denser shapes and moves
about 2.7 times faster.

Nearer things look larger and move faster — that alone is enough to give a
flat screen some depth.

The pattern stops for readers whose system asks for reduced motion, and it
does not appear in print.

### Languages

English and Japanese cover the whole site; the other twelve have this front
page only.

The **Latin** version marks vowel length with macrons (Ryūma, Ūniversitās
Niigatēnsis). Latin distinguishes words by vowel length, so leaving them out
would simply be inaccurate.

The **Hebrew** version has vowel points on proper nouns only
(רְיוּמָה אוֹרִיטָה). Modern Hebrew points only words whose reading cannot be
guessed, and a foreign name is the clearest case.

The **Korean** headings are set in the script of the *Hunminjeongeum*, the
1443 promulgation of the Korean alphabet, in a face reconstructed from the
letterforms of the *Haerye* edition.

### Type

Headings are set in a serif face. Japanese serif faces, however, carry the
Greek and Cyrillic lowercase in the sloped form used for mathematical
variables, which would leave the Greek headings leaning over. A different
face is chosen for each script to avoid this.

### How it is made

Built with Hugo and Blowfish, published on Netlify. The text is Markdown and
every visual adjustment lives in a single stylesheet; the theme itself is
untouched.

The email address is not written into the HTML. It is assembled when the page
opens.
