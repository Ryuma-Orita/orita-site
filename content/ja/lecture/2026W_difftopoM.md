## 日程・授業内容

2026年10月8日現在の予定です。授業内容は進度に応じて調整することがあります。

| 回 | 日程 | 授業内容 |
|:--:|:--|:--|
| 第1回 | 2026/10/8 | **復習・Morse関数**<br>微分・連鎖律を復習し、Hesse形式、非退化臨界点、指数を定義する。球面・トーラスの高さ関数を例に、臨界点の孤立性とコンパクト多様体上での有限性を学ぶ。 |
| 第2回 | 10/22 | **Morse補題・射影平面の例**<br>Morse補題による非退化臨界点の局所標準形を学び、Hadamard補題と等位集合の局所的な形を確認する。実射影平面上の関数について、局所座標を用いて臨界点と指数を計算する。 |
| 第3回 | 11/5 | **Morse関数の存在・摂動安定性**<br>Sardの定理を用いてMorse関数の存在を示し、Morse関数全体の開性・稠密性を学ぶ。十分小さい摂動で指数ごとの臨界点数が保たれることを確認する。 |
| 第4回 | 11/12 | **勾配ベクトル場と勾配流**<br>Riemann計量と勾配ベクトル場を定義し、勾配が計量に依存することを確認する。負勾配流に沿う関数値の単調性と臨界点への収束を学び、球面や鞍点の例を調べる。 |
| 第5回 | 11/19 | **安定多様体と不安定多様体**<br>安定・不安定多様体を定義し、その次元と臨界点の指数の関係を学ぶ。球面・トーラス・実射影空間を例に、不安定多様体による多様体の分割と流線の接続を調べる。 |
| 第6回 | 11/26 | **ハンドル接着とReebの定理**<br>臨界値を含まない区間での劣位集合の変化と、臨界値を通過するときのハンドル接着・胞体付加を学ぶ。トーラスの例を確認し、臨界点が二つの場合のReebの定理を証明する。 |
| 第7回 | 12/3 | **横断性とMorse–Smale条件**<br>部分多様体の横断的な交わりと次元公式を学び、Morse–Smale条件を定義する。流線に沿う指数の減少、トーラスを傾けたときの接続の変化、Morse–Smale条件の生成性を確認する。 |
| 第8回 | 12/10 | **勾配流線のモジュライ空間**<br>流線を時間の平行移動で同一視するモジュライ空間を定義する。正則等位集合による切断とシリンダー構造から次元公式を導き、不安定球面および球面・トーラスの例を調べる。 |
| 第9回 | 12/17 | **コンパクト性と壊れた軌道**<br>壊れた軌道を加えるモジュライ空間のコンパクト化を学ぶ。指数差1の場合の流線の有限性と、指数差2の場合の境界の記述・貼り合わせを確認し、境界点が偶数個になる理由を考える。 |
| 第10回 | 12/24 | **Morse複体と境界作用素**<br>鎖複体とホモロジーを導入し、流線の個数をmod 2で数えてMorse複体を構成する。1次元モジュライ空間の境界から$\partial^2=0$を証明し、円周・球面のMorseホモロジーを計算する。 |
| 第11回 | 2027/1/7 | **Morseホモロジーの計算例**<br>トーラス・変形した球面・実射影平面のMorseホモロジーを計算する。境界作用素の核と像の役割を確認し、臨界点数の交代和とEuler標数の関係を調べる。 |
| 第12回 | 1/21 | **Morseホモロジー定理とMorse不等式**<br>特異ホモロジーとの同型を与えるMorseホモロジー定理を学び、弱い・強いMorse不等式とEuler標数の公式を導く。完全Morse関数や複素射影空間・種数2の曲面を例に、臨界点数の下限を求める。 |
| 第13回 | 2/4 | **総合確認・Floer理論への展望**<br>Morse複体の構成と$\partial^2=0$、Morse不等式までの流れを振り返る。Hamilton流の非退化固定点とArnoldの評価を紹介し、トーラスの具体例とMorse理論・Floer理論の対応を学ぶ。 |
